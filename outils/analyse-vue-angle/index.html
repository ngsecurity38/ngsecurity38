2 bis · Relevé de l'étude

Valeurs obtenues par lecture optique d'un document scanné. Un chiffre mal reconnu fausserait la mesure d'angle : vérifier chaque ligne au survol, contre l'extrait d'origine.

L'étude annonce une caméra thermique, mais le capteur choisi est un format visible. Un microbolomètre se désigne par sa matrice et son pas de pixel, pas en pouces : tant que le capteur n'est pas corrigé dans le bloc 2, l'angle de champ calculé est faux.

Texte lu par l'outil

Ce que l'outil a réellement lu dans le PDF, les passages retenus surlignés. Si une caractéristique manque alors qu'elle figure bien dans l'étude, c'est ici qu'on voit pourquoi : copier ce texte et le transmettre suffit à faire ajouter la formulation — inutile de sortir le document du dossier client.

Valeurs relevées dans l'étude, chacune avec sa page d'origine — survoler une ligne pour voir l'extrait. « Reprendre » recopie la valeur dans le bloc 2 : à n'utiliser que si le matériel posé correspond effectivement à l'étude. Sinon, saisir ce qui est réellement monté : c'est justement l'écart qui fait l'intérêt du relevé.

La vue demandée est la référence contractuelle. Déposer directement le PDF de l'étude : l'outil affiche les pages, on choisit celle qui porte la vue attendue et on recadre dessus. Une image seule (capture validée, photo de repérage) fait tout aussi bien l'affaire. L'image réglée est la capture prise après installation.

Recalage manuel
